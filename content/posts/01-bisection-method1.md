이분법(Bisection Method)의 첫 포스팅은 "가장 단순하지만, 절대로 실패하지 않는 강력함"을 전달하는 데 집중합니다.

실생활 및 공학 응용 문제로는 "자율주행 차량의 긴급 제동 거리(Safe Braking Distance) 역산 문제"를 연결하려고 합니다.

---

### 왜 '자율주행 긴급 제동 거리'인가?

1. **직관적인 물리 현상:** 속도가 높아질수록 공기 저항(속도의 제곱 $v^2$)과 노면 마찰력이 비선형적으로 작용하여 멈추는 데 필요한 거리가 늘어납니다.
2. **역산(Inverse Problem)의 필요성:** "속도 $v$일 때 제동 거리 $d$를 구하는 것"은 쉬운 직진 계산이지만, "제동 한계 거리 $d_{limit}$가 $50\text{ m}$로 제한되어 있을 때, 안전하게 멈출 수 있는 최대 진입 속도 $v_{max}$를 역산하는 문제"는 비선형 방정식을 풀어야 하는 수치해석의 영역입니다.
3. **이분법의 장점 극대화:** 빗길, 빙판길 등 노면 상태에 따라 마찰 계수가 급격히 변하거나 복잡한 테스트 함수가 쓰일 때, 미분값을 구하기 어렵더라도 이분법은 "속도 범위($0 \sim 200\text{ km/h}$)만 잡아주면 100% 안전하게 해를 찾아내는 특성"을 보여주기에 최적입니다.

# [수치해석 01] 이분법(Bisection Method): 자율주행차는 어떻게 제한된 거리 안에 멈추는 속도를 찾을까?

> **요약:** 세상에서 가장 단순한 알고리즘이 때로는 가장 강력합니다. 사잇값 정리 하나만으로 동작하지만 절대 실패하지 않는 **이분법(Bisection Method)**의 원리를 이해하고, 자율주행 차량의 안전 진입 속도를 역산하는 실전 문제에 적용해 봅니다.

---

## 1. '단순함'이 만드는 절대적인 안정성

수치해석에서 해를 찾는 알고리즘(Root-finding)은 다양합니다. 속도가 매우 빠른 뉴턴-랩슨(Newton-Raphson) 기법도 있지만, 기울기(미분값)가 0이 되거나 초깃값을 잘못 잡으면 해를 찾지 못하고 발산해 버리는 치명적인 약점이 있습니다.

반면 이분법(Bisection Method)은 고등학교 과정에서 배우는 **사잇값 정리(Intermediate Value Theorem)** 하나만을 이용합니다.

> 연속함수 $f(x)$에 대해 $f(a)$와 $f(b)$의 부호가 다르다면($f(a) \cdot f(b) < 0$), 구간 $[a, b]$ 사이에 $f(c) = 0$을 만족하는 해 $c$가 적어도 하나 존재한다.

구간을 절반씩 쪼개어가며 해가 존재하는 쪽으로 범위를 좁혀나가는 이 방식은 속도는 느릴지언정, "조건만 맞으면 100% 해를 찾아낸다"는 강력한 안정성을 보장합니다.

---

## 2. 실전 문제: 자율주행 차량의 안전 진입 속도 역산

자율주행 차량이 도로를 달리고 있습니다. 전방에 장애물이 감지되었고, 현재 도로 상황(빗길 마찰계수, 공기저항)에서 장애물과 충돌하지 않고 안전하게 멈출 수 있는 남은 거리가 정확히 $50\text{ m}$입니다.

차량의 제동 거리 모델 방정식은 공기저항과 노면 마찰을 고려해 다음과 같이 비선형 방정식으로 주어진다고 가정해 봅시다.

$$d(v) = \frac{m}{2k} \ln\left(1 + \frac{k v^2}{m g \mu}\right)$$

* $v$: 차량 진입 속도 ($\text{m/s}$)
* $m$: 차량 질량 ($1500\text{ kg}$)
* $\mu$: 빗길 타이어 마찰 계수 ($0.4$)
* $k$: 공기저항 계수 ($0.35$)

우리가 풀어야 할 문제는 $d(v) = 50\text{ m}$가 되게 하는 최대 속도 $v$를 찾는 것입니다. 이를 수치해석용 방정식으로 바꾸면 다음과 같습니다.

$$f(v) = d(v) - 50 = 0$$

---

## 3. 이분법 알고리즘 수행 과정

1. **초기 탐색 구간 설정:** 속도가 $0\text{ m/s}$일 때 제동 거리는 $0\text{ m}$이므로 $f(0) = -50 < 0$입니다. 속도가 $60\text{ m/s}$ ($216\text{ km/h}$)일 때 제동 거리는 $50\text{ m}$를 훨씬 넘으므로 $f(60) > 0$입니다.
* 탐색 구간: $a = 0$, $b = 60$ ($f(a) \cdot f(b) < 0$ 만족)


2. **중점 계산:** $c = \frac{a + b}{2} = 30\text{ m/s}$ ($108\text{ km/h}$)
3. **부호 판정 및 구간 축소:**
* $f(c)$의 값을 계산하여 부호를 확인합니다.
* $f(a) \cdot f(c) < 0$이면 해는 $[a, c]$ 사이에 있으므로 $b = c$로 설정합니다.
* 그렇지 않다면 해는 $[c, b]$ 사이에 있으므로 $a = c$로 설정합니다.


4. **반복:** 오차 범위(예: $10^{-5}$) 안으로 들어올 때까지 2~3 과정을 반복합니다.

---

## 4. 파이썬 핵심 구현 코드 미리보기

```python
import numpy as np

def braking_distance_error(v, target_d=50.0):
    m, g, mu, k = 1500.0, 9.81, 0.4, 0.35
    d = (m / (2 * k)) * np.log(1 + (k * v**2) / (m * g * mu))
    return d - target_d

# 이분법 구현
a, b = 0.0, 60.0  # 탐색 속도 범위 (0m/s ~ 60m/s)
tol = 1e-5

for step in range(100):
    c = (a + b) / 2.0
    f_c = braking_distance_error(c)
    
    if abs(f_c) < tol or (b - a) / 2.0 < tol:
        print(f"[{step+1}회 반복] 안전 진입 속도: {c:.2f} m/s ({c*3.6:.2f} km/h)")
        break
        
    if braking_distance_error(a) * f_c < 0:
        b = c
    else:
        a = c

```

---

## 5. 수치해석적 인사이트: 느리지만 절대 쓰러지지 않는 무기

이분법은 한 번 반복할 때마다 탐색 구간이 정확히 $\frac{1}{2}$로 줄어듭니다. 이를 선형 수렴(Linear Convergence)이라고 부릅니다.

* $N$번 반복 후 오차 범위: $\frac{b - a}{2^N}$
* 약 20번만 반복하면 오차는 초기 구간의 $10^{-6}$ 배 이하로 줄어듭니다.

최신 AI 기반 시뮬레이션이나 복잡한 물리 엔진에서도, 해가 엉뚱한 곳으로 튀는 것을 방지하기 위해 **초기 해의 범위를 안전하게 가두는 'Guardrail' 역할로 이분법을 여전히 가장 먼저 실행**하곤 합니다.
