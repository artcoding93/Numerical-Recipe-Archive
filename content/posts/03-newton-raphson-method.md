# [수치해석 03] 뉴턴-랩슨(Newton-Raphson) 기법: 접선의 기울기로 해를 향해 Jump하라

> **요약:** 사잇값 정리로 안전하지만 느리게 범위를 좁히던 이분법(Bisection Method)의 답답함을 날려버릴 차세대 알고리즘이 등장합니다. 함수의 **미분값(접선의 기울기)**을 활용하여 해를 향해 빠르게 수렴하는 **뉴턴-랩슨(Newton-Raphson) 기법**의 원리와 실전 응용을 다룹니다.

---

## 1. 이분법의 답답함을 깨부수는 '접선의 기울기'

이분법은 절반씩 탐색 구간을 줄여나가기 때문에 수렴 속도가 느립니다(선형 수렴, Linear Convergence).

반면 **뉴턴-랩슨(Newton-Raphson) 기법**은 현재 위치에서 함수 $f(x)$의 **접선을 그리고, 그 접선이 x축과 만나는 지점(x절편)을 다음 탐색 위치로 지정**합니다.

![alt text](image.png)

이 과정을 수식으로 정리하면 다음과 같은 뉴턴-랩슨의 핵심 점화식이 도출됩니다.

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
$$

- $x_n$: 현재 탐색 지점
- $f(x_n)$: 현재 지점에서의 함수값
- $f'(x_n)$: 현재 지점에서의 미분값(접선의 기울기)

---

## 2. 실전 문제: 전자 회로(SPICE 엔진)의 비선형 다이오드 동작점 도출

전자 회로 시뮬레이터(예: SPICE)에서 다이오드(Diode)가 포함된 회로의 전류-전압 관계를 해석하려면 **Shockley 다이오드 방정식**을 풀어야 합니다.

$$
I_D = I_S \left( e^{\frac{V_D}{\eta V_T}} - 1 \right)
$$

전원 전압 $V_{DD} = 5\text{V}$, 저항 $R = 1\text{k}\Omega$ ($1000\Omega$), 포화 전류 $I_S = 10^{-12}\text{A}$, 유효 열전압 $\eta V_T = 0.026\text{V}$일 때, 키르히호프 전압 법칙(KVL)에 의한 회로 방정식은 다음과 같은 지수형 비선형 방정식이 됩니다.

$$
f(V_D) = \frac{5 - V_D}{1000} - 10^{-12} \left( e^{\frac{V_D}{0.026}} - 1 \right) = 0
$$

이 방정식의 해(다이오드 양단 전압 $V_D$)를 구하기 위해 미분값 $f'(V_D)$를 구하면 다음과 같습니다.

$$
f'(V_D) = -\frac{1}{1000} - \frac{10^{-12}}{0.026} e^{\frac{V_D}{0.026}}
$$

---

## 3. 파이썬 구현 코드 (Google Colab)

```python
import numpy as np

# 1. 회로 방정식 f(V_D) 정의
def f(v):
    return (5.0 - v) / 1000.0 - 1e-12 * (np.exp(v / 0.026) - 1.0)

# 2. 회로 방정식의 1차 도함수 f'(V_D) 정의
def df(v):
    return -1.0 / 1000.0 - (1e-12 / 0.026) * np.exp(v / 0.026)

# 3. 뉴턴-랩슨 알고리즘 실행
def newton_raphson(v0, tol=1e-7, max_iter=50):
    v = v0
    print(f"초기 예측값 V_0 = {v:.4f} V\n" + "-" * 40)

    for step in range(max_iter):
        f_val = f(v)
        df_val = df(v)

        # 뉴턴-랩슨 점화식 적용
        v_next = v - f_val / df_val
        diff = abs(v_next - v)

        print(f"[{step+1}회 반복] V_D = {v_next:.7f} V (오차: {diff:.2e})")

        if diff < tol:
            return v_next
        v = v_next

    return v

# 다이오드 턴온 전압 근처인 0.6V를 초깃값으로 설정
v_sol = newton_raphson(v0=0.6)
```

## 4. 이분법 vs 뉴턴-랩슨 속도 비교

동일한 정밀도를 얻기 위해 필요한 반복 횟수를 비교하면 뉴턴-랩슨의 빠른 수렴 성능을 체감할 수 있습니다.

- **이분법:** 구간을 반복해서 절반으로 줄이는 선형 수렴 방식입니다. 초기 구간 폭이 1V일 때 구간 폭을 $10^{-7}$V 미만으로 줄이려면 24회 분할이 필요합니다.
- **뉴턴-랩슨:** 위 초기값에서는 소수의 반복으로 수렴합니다. 단, 반복 횟수는 초기값과 종료 조건에 따라 달라집니다.

뉴턴-랩슨 기법은 단순근 근처에서 충분히 매끄러운 함수에 적용할 때 오차가 대략 제곱에 비례하여 줄어드는 **2차 수렴(Quadratic Convergence)** 특징을 가집니다.

## 5. 수치해석적 인사이트

뉴턴-랩슨은 매우 강력한 알고리즘이지만, 다음과 같은 **한계점**을 지니고 있습니다.

1. **도함수 $f'(x)$가 필요함:** 해석적 미분이 어렵거나 함수가 매끄럽지 않으면 직접 적용이 까다로울 수 있습니다. 자동 미분이나 수치 미분으로 보완할 수 있습니다.
2. **기울기가 0에 가까운 지점($f'(x) \approx 0$):** 분모가 매우 작아져 다음 탐색 위치가 크게 이동하거나 계산이 실패할 수 있습니다.
3. **초깃값에 민감함:** 초기 추정값에 따라 다른 근으로 수렴하거나 발산할 수 있습니다.

이러한 한계를 극복하기 위해 실전에서는 **이분법과 뉴턴-랩슨을 결합한 하이브리드 전략**이나, 도함수 대신 두 점의 함수값으로 기울기를 근사하는 **할선법(Secant Method)** 등을 사용합니다.
